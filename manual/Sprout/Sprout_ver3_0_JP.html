1. Introduction

Sprout は"Electro-Smith Daisy Seed”をコアとする高解像度 (96kHz/24bit) のマルチエフェクトプロセッサーです。

プリセットで以下のエフェクトが利用できます。

  • Tape Echo (テープのよれまで再現したテープエミュレーションディレイ)
  • Modern Delay (最大10秒のディレイタイム。ピッチシフトや逆再生が可能)
  • FDN Reverb (反響音のピッチシフト (いわゆるシマー）が可能)

ver 2.0:

  • Repeater (入力された音を記録し、範囲を指定してリピートするエフェクト)
  • Sampler (16x16のスロットにサンプルを配置し、Gate入力時に再生)

ver 3.0:

  • String Resonator (入力音で仮想的な弦を共鳴させるエフェクト。エレキベース / エレキギターのモード付き)
  • MIDI 入力 (CC によるパラメータ操作、String Resonator のノート演奏、Repeater の MIDI Clock 同期)

さらに、独自のカスタムエフェクトを作成してアップロードすることが可能です。

詳細はGitHubのプロジェクトページを参照してください: https://github.com/centrevillage/SproutExample

3.4. Repeater (ver 2.0)

現在のエフェクトが Repeater のとき、 Sprout LED が水色に点灯します。
このエフェクトを利用するときは、GATE Input に同期用のクロック信号を入力してください。
MIDI Clock にも同期できます (ver 3) (「4.3. Repeater」参照)。

Repeater エフェクトには Listen と Play の二つの状態があります。
初期は Listen 状態になっています。

Listen 状態のとき、入力されたオーディオ信号は最大16ステップ分の長さで記録され続けます。
また、入力オーディオ信号がそのまま出力されます。

Play 状態のときは Listen 状態の時に記録したオーディオを再生します。

Wind Button を押すと、 Listen と Play の状態が相互に切り替わります。

現在の状態は、Meter LED の点灯状態で把握することができます。
Listen 状態のときは再生範囲を表す色が青か紫色(逆再生時)です。
Play 状態のときは 再生範囲を表す色が緑か赤色(逆再生時)です。
また、再生中のステップ位置が明るく点灯します。

また、以下の操作によって再生するオーディオ位置や速度などを変更することができます:

OperationNameDescription
TimeSpeed再生速度を変更します。

左側の位置では再生速度が遅くなり、中間の位置で等速、右側の位置では再生速度が速くなります。

再生速度を変えた場合にも常にクロック同期されます。
SunStart Position再生開始位置を変更します。
WetLength再生ステップ長さを設定します。
ステップ長さは正負の値が設定可能です。

ノブが右側の位置では正の値が設定可能で、オーディオを順再生します。
ノブが左側の位置では負の値が設定可能でオーディオを逆再生します。
Wind + SunRandom Start PositionPlay 状態での再生開始位置をランダムに移動します。
値が大きいほど、遠くのステップに移動しやすくなります。
Wind + WetDry / Repeat BalancePlay 状態での入力オーディオ信号と再生オーディオ信号の音量バランスを設定します。

一番左の位置ではDry=100%、Repeat=0%。
中間の位置でDry=100%、Repeat=100%。
一番右の位置でDry=0%、Repeat=100%。

3.5. Sampler (ver 2.0)

現在のエフェクトが Sampler のとき、 Sprout LED が紫色に点灯します。

このエフェクトを利用する場合は、必ずMicro SD Cardを挿入した状態でモジュールを起動してください。
（SD Cardが挿入されていない場合、または “samples” ディレクトリが存在しない場合はこのエフェクトは選択できません）

SD Cardには16バンク×16スロット（合計256サンプル）のオーディオファイルを配置することができます。

Sampler エフェクトでは、SD Card内に保存したサンプルを、GATE Input にトリガー信号が入力されたタイミングで鳴らすことができます。
また、オーディオ入力信号をリアルタイム録音することも可能です。

オーディオの長さは SD Card の容量のみによって制限されます。
（モジュールのメモリ上の制約はありません）

3.5.1. SD Card Condition

利用可能なMicro SD Cardは以下の条件を満たす必要があります:

  • 容量が32GB以下
  • アプリケーションパフォーマンスクラスがA2

Micro SD Card の動作確認状況は以下です:

NameConfirmation
Gigastone 32GB 4K Camera ProOK (Write & Read)

3.5.2. Sample File

SDカードのルートディレクトリ直下に “samples” ディレクトリを作成し、各サンプルファイルを配置します。

ファイル名は以下のフォーマットに従ってください:

「バンク番号(1-16)」_「スロット番号(1-16)」.wav

(例: 1_1.wav, 2_3.wav 等)

wavファイルは44.1/48/96kHzの16/24bitまたは32bit floatのステレオに対応しています。
トラック情報などのメタ情報を含むファイルも、そのまま読み込めます (ver 3)。

録音を行った場合は、自動的に対応するwavファイルがSDカード内に作成されます。
そのときのフォーマットは96kHz&32bit float&ステレオ固定となります。

3.5.3. Operation

Sampler エフェクトには Play と Record の二つのモードがあります。
初期では Play モードになっています。
Wind + Sprout Button を押すことで二つのモードを相互に切り替えることができます。
現在のモードは Sprout LED で点灯状態で判別でき、Playモード中は紫色で常時点灯、Record モード中は紫色で点滅します。

3.5.3.1. Play Mode

バンク選択

Wind + Time Knobでバンクを変更することができます。
バンク毎に Time LED と Meter LED の色が変わります。（赤->緑->青->黄-> ...)

スロット選択

Time Knob でスロットを変更することができます。
選択可能なスロット位置がバンクの色で Meter LED に表示されます。
選択中のスロット位置は明るい色で表示されます。

また、CV入力によっても選択スロットを変更することができます。

サンプル再生

GATE Input にトリガー信号を入力すると、選択スロットのサンプルを再生します。
また、L/R Input にオーディオ信号が入力されている場合は、再生中のサンプルの音声とミックスされた信号が出力されます。

クリックノイズを抑えるため、再生中に再トリガーしたときは前の音から新しい音へ約1ミリ秒のクロスフェードがかかり、サンプルの終わりでは最後の約1ミリ秒がフェードアウトします (ver 3)。
長さは設定ファイルで変更 / 無効にできます (「5. Settings File (config.ini)」参照)。

再生速度変更

Sun Knob でサンプルの再生スピードを変更できます。
中間の位置で等速で、左側が減速、右側が加速になります。

サンプル再生音量変更

Wet Knob でサンプル再生音量を変更できます。

テープサチュレーターエフェクト

Wind + Sun Knob でテープサチュレーターエフェクトの量を設定できます。
テープのよれによるフラッター効果と、帯域フィルターの効果を再現します。
最小値でエフェクト0%、最大値で100%です。

リバーブエフェクト

Wind + Wet Knob でリバーブエフェクトの量を設定できます。
このリバーブは FDN Reverb エフェクトのアルゴリズムを単純化したものです。
最小値でエフェクト0%、最大値で100%です。

3.5.3.2. Record Mode

入力オーディオ信号のスルー出力

Play モードと同様に、入力オーディオ信号は録音中かどうかにかかわらず常にオーディオ出力されます。

バンク/スロット選択

Play モードと同様に Wind + Time Knob でバンク選択、Time Knob でスロット選択が可能です。
Play モードと違い、サンプルが存在しないバンクやスロットも選択可能です。
(この場合選択スロット位置の Meter LED が弱めのバンクカラーで点灯します)

録音開始/終了

Sprout Button を押すと録音状態になり、入力されているオーディオ信号を選択スロット位置に録音開始します。
録音中は Sprout LED が赤色に点灯します。

再度Sprout Button を押すと録音終了し、Sprout LEDが紫点滅状態に戻ります。

録音可能な長さは、SDカードの空き容量によって決まります。

また、もう一つの録音開始方法として、Sprout Button を押したままの状態で、 Gate Input にクロック信号を入力することで、クロック信号に同期して録音開始することができます。
この場合も、再度 Sprout Button を押すと録音終了します。

リバーブエフェクト

Play モードと同様に、Wind + Wet Knob でリバーブエフェクトの量を設定できます。
初期設定では、録音されるのは入力された音だけで、リバーブエフェクトは出力にだけかかります。
設定ファイルで、録音されるサンプルにリバーブエフェクトを含めることもできます (「5. Settings File (config.ini)」参照)。

3.6. String Resonator (ver 3)

現在のエフェクトが String Resonator のとき、Sprout LED がエメラルドグリーンに点灯します。

String Resonator は、入力されたオーディオ信号で仮想的な弦を共鳴させるエフェクトです。
GATE Input のトリガーで弦を弾き (ストラム)、CV Input (V/oct) で音程を指定できるので、音源としても使えます。
Mutable Instruments Rings の Sympathetic Strings モデル (MIT License、「10. License」参照) をもとに、エレキベースとエレキギターのモードを加えています。

出力されるのは弦の音だけです (Dry の信号は含まれません)。
Meter LED には出力レベルがエメラルドグリーンで表示されます。

Wind + Time Knob で弦の構成 (ボイスモード) を選びます。
ノブの左から順に次の6つのモードがあり、Wind Button を押している間は Time LED の色で現在のモードが表示されます。

G青エレキギター。4ボイス (1ボイスに弦2本)。基準音 C3。

3.6.3. Parameters (B / G)

ボイスモードが B (エレキベース) / G (エレキギター) のとき、次のパラメータがあります。

どちらも1ボイスは2本の弦 (弦の水平方向と垂直方向の振動) でできていて、わずかに異なる音程と減衰で鳴ることで、実際の弦の二段階の減衰やうなりを再現します。
音は中央に定位します (L / R は同じ信号)。
B は1ボイスなので、ストラムのたびに同じ弦を弾き直します。

OperationNameDescription

SunHardness弾く強さ。

3.6.4. Strum / Pitch / Excitation

ストラム (GATE Input)

GATE Input にトリガー / ゲート信号を入力すると、信号の立ち上がりで次のボイスの弦を弾きます (ストラム)。

ゲートが40ミリ秒より長く ON のときは、ON の間そのボイスが減衰せずに鳴り続けます。
OFF にすると Wet Knob (Damping) の減衰に戻ります。
短いトリガーでは Wet Knob の減衰のまま鳴ります。

音程 (CV Input)

CV Input は V/oct の音程入力です。
弦の音程は、基準音 + Transpose + CV Input の電圧 (1V = 1オクターブ) で決まります。
最後にストラムしたボイスの音程は CV Input に追従します。

CV Input の精度は「3.6.6. CV Calibration」で校正できます。

励振 (L/R Audio Input)

L/R Input に入力したオーディオ信号で、最後にストラムしたボイスの弦を共鳴させます。
入力はストラムのたびに L と R が交互に使われます (R Input が未接続のときは L Input の信号が R にも入ります)。

L Input が3秒以上無音のときは、内部の励振 (1 / 2 / 4 / 8 はノイズバースト、B / G は指やピックで弾いた波形) でストラムのたびに弦を弾きます。
L Input に音が入ると、すぐに入力信号による共鳴に戻ります。
String Resonator を選択した直後は内部の励振になっています。

MIDI

MIDI のノートでも弦を弾けます (「4. MIDI」参照)。

3.6.5. Pitch Detection Mode

Wind Button を押しながら Sprout Button を押して離すと、ピッチ検出モードの ON / OFF が切り替わります。
ON の間は Sprout LED がゆっくり明滅します。

ピッチ検出モードでは、R Input に入力した単音 (VCO の基本波形など) の音程を検出し、最後にストラムしたボイスの音程がそれに追従します。
Transpose と CV Input の電圧は、検出した音程に加算されます。
励振には常に L Input を使います (L Input が3秒以上無音のときは内部の励振)。

ピッチ検出モードは電源を切っても保持されます。ほかのエフェクトに切り替えると OFF になります。

3.6.6. CV Calibration

正確に 1V/oct で追従する VCO を使って、CV Input の V/oct の精度 (0V の位置と1オクターブあたりの幅) を校正できます。
校正値は電源を切っても、ファクトリリセット (「7. Factory Reset」参照) をしても保持されます。

準備するもの:

  • 1V/oct で正確に追従する VCO
  • VCO の V/oct 入力に送る CV 源 (キーボード、シーケンサなど) と、その出力を分岐するマルチプル

手順:

  1. String Resonator で Wind Button を押しながら Sprout Button を2秒長押しします。
    校正モードに入り、Sprout LED が橙色に点滅し、音が止まります。Meter LED の一番上がゆっくり点滅します。
  2. CV Input のケーブルを抜いた状態で Sprout Button を押します (0V の測定)。
    Meter LED の一番上が点灯します。
  3. CV 源の出力を分岐して CV Input と VCO の V/oct 入力の両方に入力し、VCO の出力を R Input に入力します。
  4. CV 源の電圧を変えるたびに Sprout Button を押します (1回の測定は0.2秒)。
    測定するたびに Meter LED が上から1つずつ点灯します。
    2点以上、1オクターブ以上の範囲で測定してください (4〜5点、例えば 0V 〜 4V を推奨)。
    音程を検出できなかったときは Meter LED が赤く光り、その点は使われません。
  5. Wind Button を短く押すと、校正値を計算して保存します。
    成功すると Meter LED が全て緑に、失敗すると赤に0.5秒点灯し、通常の表示に戻ります (失敗したときは前の校正値のまま)。

途中でやめるときは Wind Button を2秒長押しします (何も保存されません)。
校正値を消して工場出荷時の値に戻すときは、校正モードに入って測定をせずに Wind Button を短く押します。

4. MIDI (ver 3)

MIDI メッセージを受信して、パラメータの操作 (全てのエフェクト)、String Resonator の演奏、Repeater のクロック同期ができます。
MIDI の入出力には、別売の MIDI 拡張モジュール MIDI CoM+ を背面の MIDI Expand Connector に接続します。
接続するときは、ケーブルの赤いラインを基板の “RED” の表示の側に合わせてください (逆向きに挿さないでください)。

受信する MIDI チャンネルの初期値は1です。SDカードの設定ファイルで変更できます (「5. Settings File (config.ini)」参照)。

4.1. Control Change

全てのエフェクトで、次の CC により6つのパラメータを操作できます:

CCParameter
16Time
17Sun
18Wet
19Wind + Time
20Wind + Sun
21Wind + Wet

CC の値 0〜127 がノブの一番左から一番右の位置に対応します。
細かく変化するパラメータは、CC の値の間をなめらかにつないで変化します。

CC で変えた値は保存されず、電源を入れ直すとノブの値に戻ります。また、ノブの LED には表示されません。
CC で値を変えた後にノブを動かすと、ノブが現在の値の位置を通過したところからノブの操作が有効になります。

4.2. String Resonator

String Resonator では、次のメッセージで演奏できます:

MessageDescription
Note On / Offノートの音程 (+ Transpose) で次のボイスの弦を弾きます。CV Input の電圧は加算されません。

ノートを40ミリ秒より長く押さえていると、押さえている間そのボイスは減衰せずに鳴り続け、Note Off で Wet Knob の減衰に戻ります。
和音も弾けます (同時に鳴るのはボイスの数まで)。
VelocitySun (Brightness、B / G では Hardness) の値に加算されます。
64 で変化なし、1 でノブの範囲の半分だけ小さく、127 で半分だけ大きくなります。

設定ファイルで無効にできます (「5. Settings File (config.ini)」参照)。
Pitch Bend全てのボイスの音程を ±2半音の範囲で変えます。

ベロシティを固定値で送るシーケンサでは、ベロシティを64にするか、設定ファイルでベロシティを無効にしてください。

4.3. Repeater

Repeater は MIDI Clock に同期できます:

MessageDescription
Clock6クロック (16分音符) を1ステップとして同期します (GATE Input のクロック1回と同じ)。
Start次のクロックがステップの区切りになります。

GATE Input にクロックが入力されているときは、GATE Input が優先されます。
GATE Input のクロックが2秒以上 (遅いクロックでは間隔の4倍以上) 途切れると、MIDI Clock に同期します。

4.4. MIDI Thru

受信した MIDI Clock / Start / Continue / Stop は、そのまま MIDI 出力に送られます (全てのエフェクト)。

5. Settings File (config.ini) (ver 3)

SDカードのルートディレクトリに “config.ini” というテキストファイルを置くと、設定を変更できます。
ファイルは電源投入時に一度だけ読み込まれます (ファイルを変更したときは、モジュールの電源を入れ直してください)。
ファイルがないとき、または値が読み取れないときは初期値になります。

channel = 1
; on / off
velocity = on

[sampler]
; 0..10 (ms), 0 = off
declick_ms = 1.0
; on / off
rec_reverb = off
SectionKeyValueDescription
[midi]channel1〜16 (初期値 1)受信する MIDI チャンネル
[midi]velocityon / off (初期値 on)String Resonator でベロシティを使うかどうか (「4.2. String Resonator」参照)

6. Firmware Update

ファームウェアアップデートには二つの方法があります。
もしマイクロ SDカードをお持ちであれば、簡単にアップデートができます。
もしお持ちでない場合は、USB-DFUを使っての更新も可能です。ただし、別途DFUプログラムを用意する必要があります。

ver 2.0 以前から ver 3.0 に更新すると、保存されていた設定 (選択中のエフェクトとパラメータの値) は初期化されます。

6.1. Update by SD Card

手順:

  1. ファームウェアのバイナリファイル (“Sprout_firm_v3_0.bin”など) をSDカードのルートディレクトリに配置します。
  2. ラックの電源を落とします。
  3. Sproutモジュールをラックから外し、SDカードを挿入します。
  4. Sproutモジュールをマウントし直します。
  5. ラックの電源を入れると、自動的にファームウェアアップデートが行われます。
  6. アップデートが終わったら、SDカードからファームウェアのバイナリファイルを削除してください。
    (残しておくと、電源を入れるたびに書き込みが行われます)

6.2. Update by USB-DFU

はじめに、USB-DFUでのアップデートのために、DFUプログラムを準備する必要があります。
例えば, “dfu-util” (https://dfu-util.sourceforge.net/) や “zadig”(https://zadig.akeo.ie/) 等のプログラムがあります。

手順:

  1. PCとDaisy SeedをUSBケーブルで接続します。
  2. Daisy Seed の Reset ボタンを押します。
  3. ボタンを押してから2.5秒以内にファームウェア(“Sprout_firm_v3_0.bin”など)をDFUプログラムでアップロードします。 (2.5秒間はLEDが点滅状態になります)

7. Factory Reset

Sprout Button と Wind Button を両方押しながら電源を入れると、保存されている設定 (選択中のエフェクト、パラメータの値、String Resonator のピッチ検出モード) が工場出荷時の状態に戻ります。
全ての LED が緑色に点灯したら、ボタンを離してください。

CV Input の校正値 (「3.6.6. CV Calibration」参照) は消えません。
